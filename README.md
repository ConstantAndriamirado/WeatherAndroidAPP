# Weather Android App

Application Android développée en Java avec Android Studio dans le cadre d’un projet académique de Licence 3 Informatique.

## Présentation

Weather Android App est une application mobile permettant de consulter la météo en temps réel selon la position de l’utilisateur ou une ville recherchée.

Elle utilise la géolocalisation Android pour détecter automatiquement la position actuelle et consommer une API météo en ligne afin d’afficher les conditions climatiques.

## Fonctionnalités

* Détection automatique de la position
* Recherche de villes
* Affichage de la météo en temps réel
* Température actuelle
* Icônes météo dynamiques (soleil, pluie, nuages, orage, etc.)
* Interface simple et intuitive

## Technologies utilisées

* Java
* Android Studio
* XML
* API REST météo
* GPS / Location Services Android
* JSON

L’application nécessite :

* Accès à la localisation

## Objectif du projet

Ce projet a été réalisé dans un cadre académique afin de :

* apprendre le développement Android natif ;
* manipuler les API REST ;
* utiliser la géolocalisation ;
* traiter des données JSON ;
* concevoir une interface mobile fonctionnelle.
